问题 6：Phase 1 文件监控范围

智能文件中心应该监控哪些位置？这决定了架构复杂度。

A

仅本地 input 文件夹（最简单）

沿用现有模式。用户把文件放入 input → 自动整理。一个入口，逻辑清晰。

B

input + 桌面（推荐）

监控桌面新增文件，自动同步到 input 并归档。最符合"整理桌面"的用户场景。

C

input + 桌面 + 下载 + 自定义

完整版多源监控。用户可在设置中添加任意文件夹。最强大但 Phase 1 实现成本高。
