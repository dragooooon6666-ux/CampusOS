## 1. 封包分发

### 1.1 打包方案

| 步骤 | 内容 | 状态 |
|------|------|------|
| 1.1 | PyInstaller spec：打包 FastAPI + 前端 + 数据初始化 | ⬜ |
| 1.2 | `main.py` 加 `webbrowser.open("http://localhost:8000")` 自动打开浏览器 | ⬜ |
| 1.3 | **首次启动引导页**：检测 AI Key → 未配置弹出引导（注册链接 + 步骤） | ⬜ |
| 1.4 | **无 Key 可用**：V1 规则分类（按扩展名）+ 写作功能灰显提示"请先配置 AI" | ⬜ |
| 1.5 | `使用指南.md`：如何获取 DeepSeek/Kimi Key、基本操作说明 | ⬜ |
| 1.6 | **NSIS 安装包**：安装向导 → 选路径 → 桌面快捷方式 → 开始菜单 → 可选开机自启 | ⬜ |

### 1.2 AI Key 策略（方案 A + C）

- 首次启动 → 检测到无 Key → 弹出引导窗口
- 引导内容：DeepSeek/Kimi 注册链接 + 如何获取 Key 的步骤截图 + 跳转设置页
- 无 Key 时：文件中心可用（V1 扩展名分类），写作中心按钮灰显 + 提示"请先配置 AI"
- 用户填入 Key 后立即激活全部 AI 功能

### 1.3 交付物

## 2. 测试计划

### 2.1 自测清单（开发阶段）

| 场景 | 验证点 |
|------|--------|
| 拖拽上传 3 个不同类型文件 | 全部正确分类，无报错 |
| 写一篇新闻稿 | 生成内容格式正确、可编辑、可保存 |
| 创建项目 + 关联 2 个文件 | 关联成功，详情页正确显示 |
| 导出项目 zip | 解压后文件完整 |
| 删除文件 → 撤销 | 删除确认弹窗正常，文件确实被删 |
| AI 不可用时 | V1 规则命名回退，不崩溃 |
| 深色模式切换 | 所有页面颜色正确 |
| 大文件（>50MB） | 跳过内容提取，仅规则处理 |

### 2.2 内测（3-5 人，1-2 天）

找 3-5 个同学/学生干部，让他们：

| 任务 | 观察点 |
|------|--------|
| 下载 → 安装 → 启动 | 首次体验是否顺畅 |
| 放入自己的学生工作文件 | 分类准确率如何 |
| 试着写一篇新闻稿 | 交互是否直观 |
| 创建一个项目并关联文件 | 项目管理流程是否理解 |
| 导出项目 | 导出内容是否满足需求 |

**收集方式**：当面观察 + 记录操作困惑点 + 问卷（见第 3 节）

### 2.3 灰度发布（10-20 人，3-5 天）

内测修复后的版本，发到宣传页的等候名单用户 + 学生会/团委群。

## 3. 体验问卷

### 问卷内容

**基本信息**
- 你所在的学院/组织？
- 你的角色？（学生会干部 / 团委干事 / 社团负责人 / 班级委员 / 其他）
- 每周处理学生工作文件的数量？（<5 / 5-15 / 15+）

**功能体验（1-5 分）**
- 文件上传和分类的准确度？
- AI 写作中心生成内容的质量？
- 项目管理功能的实用性？
- 整体界面美观度？

**核心问题**
- 你最常使用的功能是？（文件分类 / 公文写作 / 项目管理）
- 什么场景下你最可能使用 CampusOS？（整理桌面 / 写新闻稿 / 评优找材料 / 换届交接 / 其他）
- 有没有分类错误的文件？举例说明
- 缺少什么功能让你觉得"要是有就好了"？
- 有没有让你困惑或不知道怎么操作的地方？
- 你会推荐给其他同学吗？（会 / 不会，原因）

**开放建议**
- 如果 CampusOS 收费（如 9.9 元/月），你会付费吗？
- 还有什么想说的？
